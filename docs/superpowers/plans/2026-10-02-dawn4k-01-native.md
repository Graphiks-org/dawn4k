# dawn4k-native Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produire un binding Dawn C généré par kextract, utilisable et vérifié sur JVM et Kotlin/Native desktop sans dépendance au backend haut niveau.

**Architecture:** Conserver des sorties kextract versionnées, séparées des fichiers manuels. Des tâches Gradle téléchargent les prébuilds vérifiés ; le JVM embarque le shared et K/N lie le static. native-smoke consomme les fonctions brutes et un oracle C contrôle les layouts.

**Tech Stack:** Kotlin 2.4.20, Gradle 9.6.1, JDK 25, kextract, kffi 1.0.0-SNAPSHOT, Dawn v8077.0.0, C11.

**Spec:** `docs/superpowers/specs/2026-10-02-dawn4k-design.md`.

## Global Constraints

- Dawn `v8077.0.0`, `chromium/8077`, révision `531028367c60ce07251ec0231c1b95bedb4495bc`.
- Header `dawn/webgpu.h` ; hash `f5cb9da17efab635daa12c5a9474e00d525809cf1330306a0eb88dee616f487f`.
- Packages générés `org.graphiks.dawn4k.raw` ; publication `org.graphiks:dawn4k-native:0.1.0-SNAPSHOT`.
- Cibles JVM macOS ARM64/Linux x64, macosArm64 et linuxX64 ; aucune cible 32 bits.
- kffi `org.graphiks:kffi:1.0.0-SNAPSHOT` au runtime ; kextract commit `e1d922eefb6b65887c6cc4bd98370ad2d7ba8b45` uniquement à la génération.
- Kotlin `2.4.20`, JDK `25`, wrapper existant `9.6.1` ; aucune dépendance Compose/Koin/Ktor pour ce binding.
- WebGPU `0.1.0-SNAPSHOT` reste évolutive ; ne pas l'ajouter comme dépendance runtime du bas niveau.
- Ne pas effacer le module template ni son travail utilisateur : le sortir du build après inspection, conserver ses fichiers jusqu'à une décision de nettoyage distincte.
- Les snippets des types générés suivent la convention kextract examinée ; confirmer leurs signatures dans la sortie réelle avant intégration.
- Aucun test d'infrastructure à créer : configuration, téléchargement, génération et packaging sont configurés puis vérifiés par leurs commandes usuelles. Conserver les tests ABI et les appels/callbacks réels du binding.

## Review Focus

1. Tar.gz corrompu, traversée de chemin ou symlink : refus avant extraction/promote, tâche 2.
2. Variante/build natif incohérent : rejet cible/révision/linkage et headers différents, tâches 2–3.
3. CallbackInfo passé par valeur et paramètre pointeur-vers-handle : oracle C et callback réelle, tâches 3–4.
4. Ressources JVM embarquées et bootstrap généré raccordé : configuration du bundle, tâche 5 ; chargement réel dans le smoke, tâche 6.
5. Klib compilé mais appels impossibles à exécuter : smoke JVM/K/N réel, tâche 6.

```kotlin
fun safeArchivePath(root: Path, entry: String): Path {
    require(!Path.of(entry).isAbsolute) { "Absolute archive entry: $entry" }
    val destination = root.resolve(entry).normalize()

    return destination
}
```

```c
    TYPE(WGPUFuture); FIELD(WGPUFuture, id);
    TYPE(WGPURequestAdapterCallbackInfo);
    FIELD(WGPURequestAdapterCallbackInfo, nextInChain);

    FIELD(WGPURequestAdapterCallbackInfo, callback);

    FIELD(WGPURequestAdapterCallbackInfo, userdata2);
```
