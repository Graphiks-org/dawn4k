### Changed
- Kotlin 2.4.0 → 2.4.10
- Gradle 9.5.0 → 9.6.1 → 9.8.0
- Added blocking pull request policy checks aligned with `CONTRIBUTING.md`.
- The template `shared` module is replaced by `:dawn4k-native`.
- Renamed the generated bindings package from `org.graphiks.dawn4k.raw` to `org.graphiks.dawn4k.native`.

### Added
- Android Vulkan and iOS Metal demo applications sharing the adaptive Compose UI, native surface ownership, lifecycle controls and mobile tests.
- Compose controls above the Metal particle demo: pause/resume, reset and GPU-limited particle counts, with a draggable title strip and close button for the transparent undecorated window.
- `:dawn4k-demo`: macOS desktop demo (Compose Desktop) rendering the `suite-demos` `ParticleScene` through the `:dawn4k` backend — a real window over a Dawn Metal surface, with the surface living inside the demo module and `:dawn4k` exposing only minimal platform-integrator accessors (`DawnContext.nativeBridge()`, `DawnDevice.nativeHandle()`, `DawnAdapter.nativeHandle()`).
- `dawn4k-native`: Dawn (WebGPU) desktop, Android, iOS and tvOS bindings generated by kextract (JVM, Android arm64-v8a/x86_64, iOS/tvOS arm64/simulator, macOS ARM64, Linux x64).
- `:dawn4k`: WebGPU backend implementing the published Graphiks contract over generated Dawn bindings, with caller-owned threading, explicit `DawnContext.processEvents()` progression, `hasPendingOperations()`, and resource-owning wrappers with registry-backed teardown. The contract includes typed usage masks, partial required limits, stable nullable descriptor slots and shared cancellable `GPUDevice.awaitLost()` observation. Context closure requires settled operations and closed children; device teardown is explicitly progressed. Shared-device concurrency opts into `DawnConfig.implicitDeviceSynchronization` (default `false`), requesting Dawn's native synchronization feature. Independent-encoder/readback and OS-thread-local error-scope witnesses execute on JVM and Kotlin/Native; no speedup is claimed. Covers the full `:dawn4k-native` Kotlin target matrix: JVM/macOS ARM64 Metal and Android Vulkan tested; Linux x64, iOS and tvOS compiled, with runtime validation requiring appropriate hosts/devices. Borrowed mapped ranges use the upstream `ArrayBuffer.wrap(address, size)` of `webgpu-api` (Graphiks-org/WebGPU#135); JVM/Android share monitor actuals.
- KMP project template (Android, iOS, Desktop)
- Clean Architecture / DDD
- Maven Central publishing via Vanniktech
- Multilingual docs (EN/FR) MkDocs + Dokka
- GitHub templates (issues, PR)
- Code of Conduct, CONTRIBUTING, SECURITY, SUPPORT, CHANGELOG

### Removed
- Template `shared` module (sample Android/iOS/desktop layers).
- `:native-smoke` module; functional validation is delegated to the shared acid test suite.

### Changed
- Replaced the Dokka GFM and Python post-processing pipeline with Dokka for Material for MkDocs.

### Fixed
- Blank Compose/Metal demo window, fixed-size surface rendering and animation stalls during mouse dragging; native UI work now runs on AppKit in common run-loop modes with explicit resource cleanup.
- Default snapshot publication version when no workflow version is provided.
